## Theorie
```bash
#!/bin/bash
# while 
echo "--- while ---"
counter=1
# while [ $counter -le 10 ]   # <= 10
while ((counter<=10))
do
    echo $counter
    ((counter++))
done

# for
echo "--- for ---"
# Liste = durch white-spaces getrennter string
data="1 2 3 4 5 6 7"
for d in $data
do
    echo $d
done

# Kommandozeilenargumente
echo "--- Kommandozeilenargumente ---"
for arg in $@
do  
    echo $arg
done

# brace expansion {}
echo "--- Brace expansion ---"
for value in {20..25}
do
    echo $value
done

echo "--- field seperator ---"
mylist="hallo welt,hello world,goede dag;ni hao"
IFS=",;"     # internal field seperator
for el in $mylist
do
    echo $el
done
```
## Übung (Even/Odd)
Create a simple script which will print the numbers 1–42 (each on a separate line) and whether they are even or odd.
Skript:
```bash
#!/bin/bash
for value in {1..42}
do
if (( value % 2 == 0 ))
then
    echo -e "$value"
else
    echo -e "\t$value"
fi
done
```

## Übung (Summe und Maximum)

Schreibe ein bash Skript das eine beliebige Menge von positiven Zahlen als Argumente aus der Kommandozeile übernimmt. Es soll die Summe und die größte Zahl ausgegeben werden. Hinweis: Verwende #@.

Skript:
```bash
#!/bin/bash
sum=0
biggest=0

for arg in "$@"
do
    sum=$((sum + arg))
if ((arg > biggest))
then
    biggest=$arg
fi
done
echo "Summe: $sum"
echo "Groesster Wert: $biggest"
```

Ausgabe:
```bash
┌──(kali㉿kali)-[~/260616]
└─$ ./sum.sh 1 3 5 6 77 5 3 3 67 7
Summe: 177
Groesster Wert: 77
```

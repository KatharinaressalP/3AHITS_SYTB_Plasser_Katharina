```bash

```
Wählt aus welche Shell für das Skript verwendet werden soll.


```bash
# Hallo Welt

# Shell Script = Textdatei mit shell Befehlen
# Befehle ergeben das gleiche Ergebnis wie wenn in der shell ausgeführt wird

echo $MYVAR Welt
echo Guten Morgen
```
MYVAR wurde in der Shell initialisiert und mit echo wird der Text von der Variable und dem nachfolgenden Text ausgegeben.

```bash
FILE_NAME=test.txt
DIR_NAME=mydir
#mkdir $DIR_NAME
echo "Irgendein Text" > $DIR_NAME/$FILE_NAME
```
Die Variablen werden auf test.txt und mydir gesetzt.
Es wird "Irgendein Text" ausgegeben und in eine Datei im Verzeichnis DIR_NAME geschrieben.

```bash
#double quotes
NAME=Katharina
TEXT="\$Hallo $NAME"
echo $TEXT
```
Die Variable NAME wird auf "Katharina" gesetzt.
TEXT wird auf $Hallo und die Variable NAME gesetzt und dann ausgegeben.

```bash
#single quotes
TEXT2='Hallo $NAME'
echo $TEXT2
```
Mit den singel quotes wird alles als Text betrachtet.

```bash
#curly braces {}

FILE=myname
echo "$FILE_001.txt"
echo "$FILE_002.txt"

echo "${FILE}_001.txt"
echo "${FILE}_002.txt"
```
Die Variable FILE wird auf myname gesetzt.
echo "$FILE_001.txt" gibt nur .txt aus weil es die Variablen FILE_001 und FILE_002 nicht gibt.
Mit {} wird die Variable von dem Text abgeteilt und richtig ausgegeben.
